SimulatedPlayback

Pause playback. Keep virtual time.

暂停真实播放，按经过的时间计算恢复位置

查看源码与安装说明 了解使用边界

你决定何时跳过内容

模拟模式暂停视频，记录开始位置、时间和倍速。恢复时跳转到计算出的新位置。模拟期间没有声音或画面，跳过的内容不会补播。

当前项目包含 Chromium 浏览器扩展和 Android ExoPlayer 集成示例。它是供测试与集成的应用层实现，没有提供浏览器内核、Android ROM 或 AOSP 框架补丁。

当前功能

从实际进度开始

根据当前播放位置和倍速计算虚拟进度，并受视频时长限制。

恢复或放弃

在弹窗中开始模拟、恢复到虚拟位置，或放弃这段虚拟进度。

可选自动触发

标签页隐藏、视频静音时可自动模拟；默认关闭，由你选择开启。

每个页面独立

页面导航、媒体源变化、刷新或关闭后结束会话，不把旧视频进度带到新视频。

能力与限制

项目当前范围
浏览器Chromium Manifest V3；Firefox 兼容性尚未验证。
媒体时长已知、可跳转的点播视频。会拒绝已识别的直播、受保护内容和广告；未知播放器的有限时长 DVR 可能无法识别，直播不在支持范围内。
网络暂停播放无法保证网站停止 MSE 拉流或其他请求，不承诺零流量。
耗电与恢复时间暂无经过验证的节电比例或延迟数据；恢复可能需要缓冲。
自动触发检测页面可见性与视频元素音量，不检测设备息屏或系统静音。

开始测试

Chromium 扩展

下载源码，在浏览器扩展管理页启用开发者模式，加载 web-extension/ 文件夹。打开或刷新 YouTube、Bilibili 视频页面，再打开扩展弹窗。

Android 示例

按仓库中 Android 构建说明运行示例并集成到自己的播放器。

在依赖某个网站的兼容性前，请先测试正常视频的开始、恢复、切换视频及后台行为。

测量与反馈

本项目尚未提供验证过的性能报告。请按 测量流程记录真实数据，并在反馈时附上设备、浏览器版本和复现步骤。
